The octet coupling

Refinements and interval patterns had to ship in one change, and the reason is a residual that closes the moment you can say how wide a number is.

Before this feature, every integer domain the surface could declare was int. An int residual has an unbounded top, so a wire dispatch got its _ for free. type Octet is the first closed numeric domain the language can spell — and the instant it exists, ticket 12 §2 makes that _ an error over 252 values the compiler can name.

So a refinement shipped on its own would have turned working programs into rejected ones, with nothing to answer the compiler in. That is the whole argument for one feature rather than two, and it was recorded in prototype 25c rather than in either ticket.

What an octet actually looks like

type Octet = int where value >= 0 and value <= 255

FrameType Classify(Octet)

Classify(1)             -> :method
Classify(2)             -> :header
Classify(3)             -> :body
Classify(8)             -> :heartbeat
Classify(0)             -> :reserved
Classify(>= 4 and <= 7) -> :reserved
Classify(>= 9)          -> :reserved

4..7 was refused, and the refusal is the more useful half. C#'s .. builds a half-open slice over indices, is not enumerable, and in pattern position already means “the rest” — which this language took in ticket 28 and runs today as Reverse([x, ..rest], acc). The rule that came out of it governs future borrowings: borrow the construct, or don't borrow the glyph.

The five scenarios

F2.2 A catch-all over a closed residual is an error. is_open/1 answers for all six components of the algebra. residual 0 | 4..7 | 9..255
F2.3 A span is exact, so it credits the certain set in full — unlike == acc, which is why it can close a residual at all. zero yecc conflicts; runs at 4, 7, 9, 255

F2.5 A guard and a type refinement cannot disagree, because one translator reads both. residual 0..128, not int <= 128

Two tickets reached further than their own examples

Both were found by running the compiler, not by re-reading the ticket. That is the same shape three features in a row have hit, and it is worth naming as a pattern rather than as two incidents.

Ticket 12 §2 was already reachable, and nobody had asked

§2 illustrates a closed residual with a declared union of atoms, and F2 was written expecting to create the closed case. It did not. §2's operative definition is contains an unbounded top — and after two guards over a bare int the residual can be 0..0: one integer, no top, closed. So _ => :zero is now an error where 0 => :zero is not, and two switch tests had been asserting the old behaviour since F7. Zero collateral in the shipped corpus, which has no all-wildcard clauses at all.

Ticket 43's head-line rule was needed today, not after 23 §2

43 puts head-counting in the future tense. Its own justification for having that half is what makes it reachable now: a residual over a two-argument function is a product, and heads/2 has always printed one line per product. Measured — forty singleton clauses over (int, atom) printed 41 head lines, one of them itself truncated. Both units are live at once, which is what “at most three of whatever it is enumerating” means when the printer enumerates two things at two depths.

What F2 declined to decide

A refined parameter gets no boundary guard. Found at the ibs prompt: Classify(300) returns :reserved, outside the Octet its own -spec declares, because the clause that matches lowers to when N >= 9 and no upper test exists anywhere in the module.

Inside beam-sharp nothing is wrong — the call-argument site rejects an int passed where an Octet is declared. What is unchecked is a caller the compiler has never seen, which is ticket 18's “forging the tag is caught, forging the payload is not” arriving on a shape that did not exist until this feature. 18 calls the exported check “genuinely optional… this ticket's decision”, so a feature may not take it.

Raised as ticket 46 · ENG-218. The sub-question with teeth is already in the emitter: a clause written >= 4 and <= 7 tests both bounds itself, so a guard on it is dead weight, while >= 9 tests one and needs the other.
