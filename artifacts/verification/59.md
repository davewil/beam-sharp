## 3. Falsification of the recommendation (C: widen kind/range, keep tag)

3.1 Wrong refusals: none found. Legitimate programs behave identically under widen: private refined-int fns with relational/literal/guard clauses (`Octet`, a two-interval refinement), float, tuple return, wildcard parameter, multi-param, run through public wrappers; and 2019/2025 AoC Day01 (3 / 6 on the worked example, **PartTwo 6770 on the real 4,732-rotation input, same as base**). Int-to-float coercion does not exist in B# (`Half(2)` is refused at compile time under both), so `is_float` on a private fn cannot refuse a checked caller. Lambdas do not go through `boundary_guards` (only named functions, bs_emit.erl:195), so widen does not touch them.

3.2 **The zero-byte claim fails on real code.** Compiling every example module (28) and the three aoc programs with base and widen and comparing the Code chunk:
- 29 of 31 modules: identical code (including Fib, whose recursive `Series` keeps no `is_integer` after erlc, and Foreign/Frame/Pipeline whose `.abstr` differ but whose code does not).
- **Shop.Pricing +9 B (2 tests)**: `Double/1` and `Free/1` are passed as function values to `List.Map`, so erlc cannot prove the argument.
- **aoc/2025/Day01 +34 B (3 tests)** and **aoc/bench/Day01 +18 B (2 tests)**: tail-recursive loops whose state is destructured from a returned tuple.
- That is 4.5, 11 and 9 B per surviving test against the brief's "5.0 B", and the tests sit inside a 673k-iteration loop. Wall time through the escript is 0.5-0.8 s either way, so this was not shown to matter, but "0 where provable, 5 where not" omits the ordinary middle. The brief's own "4176 -> 4176" appears in no out.txt; my fixture (a) without the 12-field records gives 3076 -> 3076, so the direction reproduces, the quoted number does not.
- Widen `rebar3 eunit` (full-root copy): 1446 pass, **2 fail, exactly F24.6 (`a_private_function_is_not_guarded_test`) and F37.5 (`a_private_function_carries_no_range_guard_test`)**, the two the brief says change by design. `every_aoc_program_still_compiles_test` passes. Baseline 1448/1448.
