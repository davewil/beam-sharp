## Circularity

No probe or patch is shaped to produce its own expected result.
- p52_reproduce.sh's base run is the unmodified compiler. The stand-in dependency is a plain erlc-built module in the standard `name-vsn/ebin` layout.
- The 52a check is a direct `code:which(Mod) =:= non_existing`. It does not special-case the probe's module name.
- The 52b check reads only `BSC_APPS` and the code path, with no hard-coded app names.
- The neighbour probes run the real tools.
- The corpus run uses the real examples.
The weaknesses are coverage, not manufacture:
- The 52b probe only exercises the happy layout (`mydep-1.0.0/ebin`), so owner_app's edge failures (B, C, D, E above) are untested.
- The corpus holds only OTP `using` modules.
- The 52b declaration is an env var, not a real `.app.src` reader (the brief discloses this).
