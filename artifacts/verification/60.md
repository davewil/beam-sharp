## Circularity findings
None of the three probes is circular. probe_gleam.sh records the actual rc (a refusal would print rc!=0); corpus_edges.py classifies from the files. The Gleam fixture was patched once (README notes a sed that did not apply) but the final fixture does call `marked()`. Weakness: probe_gleam.sh prints only `tail -3` of the build log, so a warning earlier in the log would be hidden; I checked full logs and found none. Path dependency only: a Hex dependency could not be tried offline, so "Gleam does not enforce" is shown for path deps only (I could not make it refuse in any configuration).

## Corrections the brief needs
1. Replace "A qualified call (...) reaches `qual_table/1` at `:538` without an import, so **the check has to sit at the call site, not only at `using`**." with "`qual_table/1` (:537) is built over the whole World, but a call with no `using` is refused ('called but never imported'); with `using Shop.Orders` a qualified call reaches the same tables, so the check has to sit at the call site (unqualified and qualified), not at `using`, which must still succeed for the public names."
2. "The one effect is on generated docs" -> add "(Gleam's default internal_modules already hides `<pkg>/internal`, so the effect does not depend on the line in the fixture; `internal_modules = []` shows the module)."
3. "7 B#-to-B# `using` edges: 4 between unrelated roots (`Jev <-> Support.Triage`)" -> list them as Jev->Support.Triage, Triage->Jev, Triage->Support.Triage, Pipeline->Shop.Collections; note 3 of the 7 target namespaces, and that one more `using Shop.Orders` line exists in unparsed exemplar 25a.
4. Drop or mark unmeasured "OTP 28's `xref` can *report* but not *refuse*"; "Run-time cost: 0" should say "by ticket 18, not measured here".
5. Line refs: `qual_table/1` head is :537, `private_table/1` head :555; `add_module_import` also reads `types`.
