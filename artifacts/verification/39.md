1. Benchmark fairness: PASS (with notes)
- All four compute the same function over the same `Deltas` list, parsed once in bench.erl; answer checked against 6770 for all four before timing (my runs: all 6770). Source bodies are the same algorithm (sign(0)=1, size_, wrap, hit, spin). bs "Sign d<0 / d>=0" differs only in clause form.

Each in a fresh VM alone: gleam 10.76, bs 16.60, erl 16.77, ex 16.59. Order/process state does not move anything beyond ~0.5%. All answers 6770.
