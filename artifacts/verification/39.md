## Corrections and overreach

1. **`+no_type_opt` is not "annotations removed, all else equal".** It disables the type pass in `beam_ssa_opt`, so the code differs too.
   - `erlc +to_asm` of `bench_erl`: the default output with tr stripped differs from the `+no_type_opt` output.
   - The `labels` count goes from 25 to 26. A `gc_bif '+'` is moved to a different place. A `line` instruction is re-placed.
   - `+no_ssa_opt` gives the same asm.
   - The brief's "instrs=26" is therefore a count, not an equality.
   - The clean test is to strip only `{tr,...}` from the `.S` and reassemble. I did that on the actual bench loop (probe C below): no change.
   - So the ticket's §3.2 wording is accurately tested by C. The brief's `+no_type_opt` result is a blunter instrument than it implies.
2. **The null is informative about the mechanism only because of probe A below.** The brief never checks that this VM's JIT reacts to tr at all. It does: a tr-only strip slows a typed-arithmetic loop by 58%.
   - Without that, a null on `+no_type_opt` would not distinguish "mechanism false" from "mechanism invisible on this JIT".
   - Even so, the null says the bench loop is insensitive to tr on OTP 25 x86. It says nothing about OTP 28 / arm64, where the ticket measured.
   - The brief's closing line, "the mechanism the ticket proposes does not move the clock", needs the qualifier "on this VM for this loop".
3. **"The 20% gap does not appear" is reported as a non-reproduction, not a refutation.** The brief mostly does this. The sentence "On this VM the mechanism the ticket proposes does not move the clock" is the only one that drifts toward refutation.
   - The title of the README row, "gap did not reproduce here", is fine.
   - The brief nowhere says the gap is unreal. I found no sentence that does.
4. **The 13 ms vs 5 ms baseline is the machine, not the input.**
   - Input has 4,732 rotations and 673,364 clicks, the same as the ticket.
   - The shuffle probe below reproduces 673,364 clicks.
   - So the iteration count matches. The sandbox is about 2.5x slower in absolute terms, which is a different CPU class, a loaded machine and an older OTP.
   - The brief does not state this. It only says "single-machine and noisy" in the README.
5. **Cosmetic:** the bench prints "all four agree on 6770" with three rows (the Gleam row was removed by `sed`). The brief's text says "three runs of 25" correctly.

## Own probes (scripts and outputs in `.../verify39/p/`)

**A. Does this JIT react to tr at all?** (`heavy.erl`, a typed-arithmetic loop with `band`/`bsr`/`bxor` ranges, N=3e6, min of 15, 5 rounds.)
```
round 1 def / no_type_opt / tr-only-stripped ms: 17.05  26.50  27.78
round 2                                          16.72  27.18  26.43
round 3                                          17.28  27.05  26.97
round 4                                          16.77  26.80  26.94
round 5                                          16.90  27.12  27.23
```
The tr-only strip (`sed` on `+to_asm`, reassembled; `diff` against the default asm shows only the tr removal) costs about 58%. So the sandbox JIT is sensitive to tr, and the bench null is a real null for that loop. It is not a blind instrument.

**B. Same sensitivity on the ticket's own shape.** `run2` (the bench's wrap + hit loop): default 84.9-87.1 ms, `+no_type_opt` 85.0-86.2 ms. Flat. The bench loop is dominated by `rem`, which tr barely helps, and its tr terms are already equal on both sides.

**C. tr-only strip on the actual `bench_erl` loop.** 40 rounds, two runs: default min 13.04 / 12.66 ms, stripped min 13.19 / 12.97 ms (medians 14.12 / 13.46 vs 13.78 / 13.38). Within 2%, inside the noise.

**D. Input order shuffled** (`shuf.escript`, 30 rounds, impl order reversed, modules reloaded each time, 673,364 clicks each):
```
orig      erl 12.80 | notype 13.21 | bs 12.89
shuffled  erl 13.15 | notype 13.21 | bs 13.10
sorted    erl 12.99 | notype 13.16 | bs 13.11
```
No ordering effect and no beam-sharp penalty.

**E. t39.escript, two extra reruns** (40 rounds each): min erl 13.12-13.21, no_type_opt 13.06-13.17, no_ssa_opt 13.14-13.17, beam-sharp 12.86-13.18 ms. Spread about 2.5%.
