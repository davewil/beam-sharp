## Circularity
The probe is not circular. Baseline accepts, prototype refuses Other.App, and the same prototype accepts Shop.Billing. The patch is mechanically simple. Gaps:
- The probe covers one refuse case and one accept case. It has no probe for the edge cases below, and those are where the patch diverges from the stated rule.
- The patch only wraps the `true` (single-module) branch of `add_import`. The namespace branch is untouched.
- A comment in the patch is garbled ("an  segment"), because a backtick-quoted word was eaten. Cosmetic.

## Gleam, independently
- Key spelling is correct: `internal_modules = ["lib/internal", "lib/internal/*"]` in the lib's gleam.toml.
- Full `gleam build` output was short (no swallowed warnings; `head` cut nothing). `gleam build` in app, with both the internal import and `@internal` call, gave rc=0 and no diagnostics.
- Gleam does honour the setting for documentation: `gleam export package-interface` lists modules `['lib']` only, and `lib.flagged` (`@internal`) is absent from the `lib` functions (`['open']`). `gleam docs build` ran clean. So "does not stop a caller" is fair, but the brief omits that the feature works for docs and the interface. That supports its "documentation and publishing" reading and is worth a sentence.

## Required corrections
1. Strike "`using` is already the single gate / one check at add_import covers both spellings". Namespace imports (`using Shop.Internal` then `Tax.Vat(n)`) bypass the prototype. Either the check also goes in `add_namespace_import`/`children`, or the namespace form must exclude internal children for outside callers. Add this as a compiler-delta item.
2. State the behaviour for top-level `Internal.X` (patch refuses everyone) and for nested `Internal` (patch uses the first one). Pick one, or say the rule is unspecified there.
3. Cite the gate at `qualified_module`/`require_imported` (bs_check.erl:4420-4431) rather than 3173.
4. Gleam row: add that `internal_modules` and `@internal` do hide items from `package-interface` and docs (executed), though not from compilation.
