# Verification of artifacts/57-negative-literals-in-refinements.md (ticket 57 / ENG-239)

Verifier: independent. Brief, probes and compiler/ untouched. Own scratch work lived in the session scratchpad.
Environment: OTP 25, Elixir 1.14.0, Gleam 1.12.0, Elm not run (brief says so too).

## Overall verdict

**CONFIRMED, with three corrections the brief should take.** Every measured row reproduces. The shim cannot
change the behaviour under test. The recommendation (Option A) survives my adversarial cases and an
end-to-end compile-and-run the brief did not do. Corrections:

1. "No checker, emitter or diagnostic change" is true of those modules but the one-line grammar fold is not
   behaviour-neutral outside refinements. It also changes `to_match/1` and `to_param/1`, which pattern-match on
   `{e_int,...}` (`bs_parser.yrl:882,930`). See C9.
2. `run.sh`'s assertions on the grammar fold are blind to a sign-dropping bug. See C11.
3. The "41 failures are OTP 25 / CLI" explanation is incomplete: at least one is a shim artefact. See C13.
