## Circularity findings

No circular prototype found, i.e. none where the expected result is manufactured. The probes that carry the brief's weight were all confirmed by independent means: P1 against the real beam, in two execution paths; the Gleam facts; the facade call chain; the collision behaviour (which came out DIFFERENT from the brief, which a manufactured probe would not).

Weaker points that are not circularity but are measurement defects, and which all lean in one direction (making the in-module alias look cheaper than it is, so Option 2 is made to look less costly, while the recommendation is against Option 2, so they do not favour the conclusion):

1. P4 baseline omits `debug_info`, which the real build uses. The delta is the same compile path before and after, but it is not the shipped path; with it the delta is 404 B not 276 B.
2. The "+10.6% of the shipped beam" is derived by arithmetic (276/2600), not measured.
3. P4 aliases carry no specs; the originals do.
4. derive.exs's regex is sound against `bsc --api`, but its glob includes non-module exemplar sketches, so the headline corpus size is wrong (not the 0-collision result).

## Unsupported or wrong claims in the brief

- "128 public functions, 100 distinct names": true of the script's output only because it counts the 7 non-module exemplar directories. Real: 100 functions, 84 distinct names, 28 modules.
- "+10.6% of the shipped beam" / "~2876": wrong. Measured with the real flags: ~+16% (+404 B, 50.5 B per alias); with specs on the aliases ~+19-20% (+496 B). "+22%" over the debug-less recompile is not the shipped figure either.
- "the shipped file is larger than the recompile because of those chunks (specs and debug info)": the extra is Dbgi (debug info, which holds specs) and the Type chunk; but crucially those chunks also GROW when aliases are added, which the extrapolation ignores.
- Facade collision "silent": false when the Elixir module is compiled after the facade is loaded (Elixir warns "redefining module"). Silent only when the facade is loaded second.
- Option 1 states "mix format keeps the quotes" as fact while the brief later says it is unverified. Code.format_string! confirms it keeps them; `mix format` not run.
- "Gleam `@external` compiled and ran (probes/62/gl)": the committed gl project never calls the external, so the shipped probe does not show a run. (I ran it myself; it works.)
- Alias scheme: the brief says nothing about the aliased forms lacking specs (Dialyzer visibility) or `missing_spec` lints.
- run.sh P4 never calls `:Shop.new(7)`, though the brief says it "then runs".
