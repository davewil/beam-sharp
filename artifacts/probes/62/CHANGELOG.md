- p02 (first run): `~S|...|` sigil collided with `|>` in one source -> script syntax error before any probe ran. Changed delimiter to `~S'...'`. No result had been seen.

- p06 (after first run): the baseline line printed `exit=$?` of the pipeline's last command (sed), not of bsc. Changed to capture bsc's own exit status into a log. Presentation only; the 'compiled' conclusion was independently visible as an empty output and a built beam.

- sizes.escript (second run): abstract_code chunk is absent (debug_info chunk holds the forms, as built by bsc's from_abstr+debug_info). Switched to Backend:debug_info/4. Still no numbers produced before the fix.
- sizes.escript (third run): beam_lib:strip/1 returns {ok,{Mod,Bin}}, not a 3-tuple. Fixed. Still no numbers produced before.
- bench_call.escript / p10 v2: v1 (kept in out/p10_v1_biased_design.out) had one loop copy per target; its null control (mode none, where 'snake' is the Pascal fn) showed 0.65 ns of loop-copy placement bias, same order as the effect being measured. v2 uses two loop copies per target and reports effect=mean(snake)-mean(pascal).
